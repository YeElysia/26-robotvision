浙江大学机械工程学院《机器视觉及其应用》课程系列实验代码与文档。

| 实验 | 内容 | 目录 |
|:---|:---|:---|

## 仓库结构

```
.
├── 实验1/                 # 实验一：双目测量
│   ├── code/              #   源代码与测试
│   ├── docs/              #   实验报告与说明

```

## 快速开始

进入对应实验目录，阅读该实验的 `docs/README.md` 获取详细说明。

```bash
# 示例：运行实验一
cd 实验1/code
pip install -r requirements.txt
python stereo_measure.py --help
```

## 说明

- 如有问题请查看对应实验目录下的文档
